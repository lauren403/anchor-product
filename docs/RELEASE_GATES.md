# Anchor v7 release gates

## Engineering — passed for this release candidate

- Production build and hosting artifact validation.
- Zero lint errors or warnings.
- Taxonomy uniqueness and reference integrity.
- Eligibility-safe recommendation tests.
- Unknown and unsupported input rejection.
- Cross-browser identifier fallback.
- Onboarding, recommendation, outcome saving and meal-detail interaction QA.
- Keyboard modal close and focus return.
- Six meal assets resolve with descriptive alternative text.
- Ecosystem links return HTTP 200 at verification time.
- Query-based moment identifiers are removed after consumption.
- Outbound links suppress referrer leakage and carry no sensitive labels.

## Governance — blocks external beta

- Clinical review and approval of each moment/support/boundary.
- APD and eating-disorder-safety review of all nutrition experiences.
- Privacy impact assessment covering device storage, exports and any proposed measurement.
- First Nations data and cultural governance review.
- Lived-experience and accessibility co-design review.
- Intended-purpose and regulatory review.
- Independent security threat model and release review.

## Ecosystem — blocks connected public launch

- Authoritative production URL for Anchor approved.
- Reciprocal ADHD Hub link implemented and tested.
- Reciprocal Body Belonging Clinic description and link implemented and tested.
- Shared navigation labels and ownership language signed off.
- Privacy-safe attribution specification approved.
- Release owner, rollback owner and incident contact named.

## Cloud — expressly blocked

Accounts, sync, remote analytics, notifications, subscriptions, clinician access and cloud personalisation must not be enabled until the relevant privacy, clinical, security and consent gates are signed.
