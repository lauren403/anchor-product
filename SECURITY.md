# Security policy

Anchor is pre-beta. Do not submit real client information, health records, Telecare notes or identifiable lived-moment data in an issue, pull request or test fixture.

Report suspected vulnerabilities privately to the designated Anchor security owner. Until that role and a private reporting channel are approved, do not open a public vulnerability issue; contact Body Belonging Clinic through its published administrative contact and use the subject `Private Anchor security report` without including sensitive details in the first message.

Supported security updates apply to the current beta candidate only. Critical and high-severity dependency or privacy findings block release.
